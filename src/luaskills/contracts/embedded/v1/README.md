# Embedded wire contract / 嵌入式线契约

This package contains the exact `contracts/embedded/v1/contract.json` and `contract.sha256` generated by LuaSkills from its compiled Rust request and response types. Each schema inside the document is an independent Draft 2020-12 root. No sibling repository or network connection is needed to regenerate the Python types.

本包保存 LuaSkills 从实际 Rust 请求和响应类型生成的精确 `contracts/embedded/v1/contract.json` 与 `contract.sha256`。文档内的每个 Schema 都是独立的 Draft 2020-12 根。重新生成 Python 类型不需要相邻仓库或网络连接。

After building with `python -m build`, run `python scripts/verify_embedded_distribution.py --wheel <exact-wheel-path> --sdist <exact-source-archive-path>`. The check imports the selected wheel with Python isolation enabled and verifies offline regeneration from only the source archive's declared files. The `Embedded contract and packaging` workflow exercises this on the minimum and current supported Python lines. Native SDK integration is a separate gate requiring the matching core library.

执行 `python -m build` 后，运行 `python scripts/verify_embedded_distribution.py --wheel <精确-wheel-路径> --sdist <精确-源码归档-路径>`。检查启用 Python 隔离模式导入选定 wheel，并仅使用源码归档的声明文件验证离线重新生成。`Embedded contract and packaging` 工作流在最低与当前受支持 Python 系列执行这些检查。原生 SDK 集成是独立门禁，需要匹配核心动态库。

From the SDK repository or source distribution / 在 SDK 仓库或源码分发包内执行：

```sh
python scripts/generate_embedded_contract.py --check
python scripts/generate_embedded_contract.py
```

An intentional upstream sync takes the exact source file path, validates its adjacent digest, and generates all outputs before writing. Check mode verifies both the upstream copy and generated Python source without writing.

主动同步上游时指定精确源文件路径，验证相邻摘要，并在写入前生成全部产物。检查模式只读验证上游副本与生成的 Python 源码。

```sh
python scripts/generate_embedded_contract.py --source /path/to/luaskills/contracts/embedded/v1/contract.json
python scripts/generate_embedded_contract.py --check --source /path/to/luaskills/contracts/embedded/v1/contract.json
```

Types are available in `luaskills.embedded_contract`. `Input*` types follow Rust deserialization rules; `Output*` types follow serialization rules. Optional fields and explicit null remain distinct. Python integers retain all bits. `TypedDict` does not perform runtime validation: bounds, unknown fields, phase transitions, authorization and completion semantics remain the core's responsibility. Unknown schema constructs stop generation rather than becoming `Any`.

类型位于 `luaskills.embedded_contract`。`Input*` 遵循 Rust 反序列化规则，`Output*` 遵循序列化规则。可省略字段和显式空值保持区别。Python 整数保留全部位。`TypedDict` 不执行运行时校验：边界、未知字段、阶段转换、授权及完成语义仍由核心负责。未知 Schema 构造停止生成，不转换为 `Any`。

`EMBEDDED_CORE_VERSION` identifies the source contract's package version. It does not prove that a separately loaded DLL with the same version supports the development interface. The release compatibility and build identity gate must still be completed before distribution.

`EMBEDDED_CORE_VERSION` 标识源契约的包版本，不证明另行加载且版本相同的 DLL 支持开发接口。正式分发前仍须完成发布兼容与构建身份门禁。
